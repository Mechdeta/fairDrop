# World ID frontend integration

Reserved location for the World ID client flow.

Before implementation:
1. Confirm the currently supported World ID / IDKit integration in the official World developer documentation.
2. Configure the app and action in the World Developer Portal.
3. Use the client only to collect and submit the supported proof response.
4. Treat backend verification as authoritative; a client-side success state is not proof of eligibility.

Do not add Arkiv or Arc dependencies in Phase 1.
